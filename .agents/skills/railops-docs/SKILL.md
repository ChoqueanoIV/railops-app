# Documentação RailOps

Documentação deve representar o estado real do repositório.

Ao concluir task estrutural:
- atualize arquitetura;
- atualize comandos;
- atualize árvore de pastas se mudou;
- atualize dependências relevantes;
- registre decisão importante em ADR quando houver trade-off duradouro.

Não documente como concluído algo ainda planejado.
