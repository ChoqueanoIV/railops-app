# Configuração local do Codex

Esta pasta existe para exemplos e configuração local do Codex.

As instruções do projeto ficam em `AGENTS.md`.

As skills versionadas do repositório ficam em:

```text
.agents/skills/<nome-da-skill>/SKILL.md
```

Não mover as skills para `.codex/skills`.

O arquivo `config.toml.example` é apenas referência. Configurações pessoais normalmente pertencem ao `CODEX_HOME` do desenvolvedor.

Antes de usar uma configuração local, confirme na documentação atual do Codex quais opções são suportadas pela versão instalada.
