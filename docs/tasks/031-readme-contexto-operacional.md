# Task 031 — Contextualização operacional do README

## Objetivo

Tornar a apresentação pública do RailOps compreensível para leitores que não
conhecem a rotina ferroviária, sem remover as instruções técnicas existentes.

## Escopo

- explicar o que é uma passagem de serviço;
- apresentar os problemas do processo baseado em papel;
- descrever o fluxo do produto em linguagem comum;
- contextualizar termos básicos da ocupação ferroviária;
- distinguir claramente o piloto gratuito de um ambiente corporativo;
- atualizar a quantidade registrada de testes do frontend.

## Restrições

- nenhuma regra de negócio ou linha de código da aplicação deve ser alterada;
- o piloto não deve ser apresentado como autorizado para dados ou uso reais;
- os ganhos devem ser descritos como objetivos do produto, sem promessas não
  comprovadas.

## Evidências

- README revisado com contexto, motivação, fluxo, público e limites;
- instruções de execução, teste e arquitetura preservadas;
- alteração restrita à documentação.
